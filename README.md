# AI Career Mentor

An AI-based career guidance and recommendation system that helps students and aspiring professionals understand career requirements, identify skill gaps, plan their learning path, find relevant courses and projects, and improve their resumes.

## Overview

Choosing the right career path can be difficult because different job roles require different skills, learning resources, practical experience, and resume requirements.

**AI Career Mentor** brings these career preparation activities together in one interactive Streamlit application.

The system takes a user's target career role, existing skills, resume, and career-related queries as input and provides personalized career guidance using AI-based techniques such as Natural Language Processing, knowledge representation, rule-based reasoning, skill matching, text similarity, and recommendation techniques.

## Features

### Career Role Selection

Select a target career role and view the skills and learning requirements associated with that career.

### Skills Roadmap

Generates a structured learning path that guides the user from fundamental skills towards advanced skills and practical development.

### Skill Gap Analysis

Compares the user's existing skills with the skills required for the selected career and identifies:

* Matched skills
* Missing skills
* Extra skills
* Career readiness percentage

### Course Recommendation

Recommends relevant courses and learning resources based on the user's career goal and identified skill gaps.

### Project Recommendation

Suggests practical project ideas related to the selected career and required skills.

### Resume ATS Analysis

Upload a resume in PDF, DOCX, or TXT format. The system extracts resume text and analyzes:

* Relevant skills
* Keywords
* Resume sections
* Missing skills
* ATS-style score
* Improvement areas

> The ATS score is an estimated score generated by the project's implemented analysis logic and is not an official score from any commercial ATS platform.

### AI Career Chatbot

Provides interactive career-related guidance using NLP and rule-based processing.

The chatbot can respond to queries related to:

* Skill gaps
* Career readiness
* Projects
* Courses
* Resume analysis
* Learning paths

### Career Roadmap PDF

Generates a downloadable PDF containing career information, skill-gap analysis, learning roadmap, recommendations, and ATS information.

## Algorithms and Processing

### Skill Path Generation

Career learning paths are represented as graphs where skills are treated as nodes and learning relationships form the edges.

The system implements:

* Breadth-First Search (BFS)
* Depth-First Search (DFS)
* A* Search

These algorithms are used for exploring paths through the career skill graph.

### Skill Gap Analysis

The system compares the user's current skills with the required skills for the selected career.

The result includes:

```text
Required Skills
      ↓
Current Skills
      ↓
Skill Matching
      ↓
Matched Skills + Missing Skills + Extra Skills
      ↓
Career Readiness
```

### Resume Analysis

The resume analysis process extracts text from the uploaded file and identifies relevant skills and keywords.

The ATS-style score considers:

* Required skill matching
* Keyword matching
* Resume sections
* Resume text length

### Course and Project Matching

The recommendation module uses **TF-IDF vectorization** and **cosine similarity** to compare the selected career and missing skills with available courses and projects.

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/KhushiYadav-26/AI-Career-Mentor.git
```

### 2. Open the Project

```bash
cd AI-Career-Mentor
```

### 3. Create a Virtual Environment

Windows:

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
streamlit run app.py
```

The application will open in your browser at the local Streamlit address.
